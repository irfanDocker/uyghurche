# ئۇيغۇرچە · Uyghurche — Free Uyghur Language Learning

A free, open-source platform for learning the Uyghur language — for kids, families, and anyone in the world who wants to connect with Uyghur culture.

**Live site:** https://Irfandocker.github.io/uyghur-learn

## Features

- **Alphabet** — All 32 Uyghur Arabic script letters with names, romanization, and example words
- **Vocabulary Grid** — Excel-style table across 7 categories (greetings, numbers, family, colors, food, animals, body)
- **Flashcards** — Flip-card practice per category
- **Quiz** — 15-question multiple-choice quiz across all vocabulary
- **Matching Game** — Match Uyghur words to English meanings (great for kids!)
- **Useful Phrases** — Everyday sentences with romanization
- **Progress tracking** — Star words you've mastered, saved in your browser

## Run Locally

No build tools needed — just open `index.html` in any browser.

```bash
git clone https://github.com/Irfandocker/uyghur-learn.git
cd uyghur-learn
open index.html
```

## Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **Deploy from branch → main → / (root)**
4. Your site will be live at `https://YOUR_USERNAME.github.io/uyghur-learn`
